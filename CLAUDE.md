# www.3elementsinc.com — notes for Claude sessions

This repo is **public** (GitHub Pages). Keep this file to build-and-deploy facts only; company notes live in the
private handbook (`threeelementsinc/handbook`, auto-loaded from `~/Documents/Apps/CLAUDE.md`).

## How the site is built

- Every page is generated by `build_site.py`. Never hand-edit the HTML.
- Edit `~/Documents/website/build_site.py`, run `python3 build_site.py` from `~/Documents/website` (writes to
  `site/`), copy `build_site.py` and `site/*.html` (and any new images) into this repo, commit, push to `main`.
  GitHub Pages deploys in about a minute.
- Pages: `index.html`, `routines.html`, `focus.html`, `purse.html`, `our-story.html`, `privacy.html`.
- Privacy policies on `privacy.html` are copied verbatim from each app's `PRIVACY_POLICY.md`. This page is the
  privacy URL used in App Store Connect for all three apps: `https://www.3elementsinc.com/privacy.html`.

## Images

- App screenshots are iPhone 17 Pro simulator captures (1206×2622), converted with
  `sips -s format jpeg -s formatOptions 82 -Z 1305 in.png --out img/<name>.jpg`.
- When replacing an image, use a **new filename**; browsers and the GitHub CDN keep serving the old one otherwise.
- `screenshot_phone()` in `build_site.py` frames a screenshot at the real screen aspect ratio.

## Checking a change

Render pages headlessly before pushing, at desktop and phone widths, for example:
```
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --hide-scrollbars \
  --window-size=1280,3200 --screenshot=out.png file://$PWD/site/routines.html
```
